# chromobench

A browser darkroom: digital RAWs and colour-negative scans printed through a physical film and paper model.

Start with **[docs/HANDOFF.md](docs/HANDOFF.md)**: what the project is, how to build, run and test it, how the work
is organised in tickets (`ttmp/`), the RAW colour investigation, WebGPU troubleshooting on a Mac, and what's next.

This repository contains private test screenshots inside ticket folders; keep it private.
